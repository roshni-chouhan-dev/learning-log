# Learning Log

Learning Log is a web app where you keep a journal of what you learn. First you register or log in. Then you can add topics (for example, chess) and write entries inside each topic.

## What I built
- Register and login: users can create an account and log in
- Topics: each user can add their own topics
- Entries: users can write entries inside a topic

## Built with
Python, Django, HTML, CSS

## How to run it
1. pip install -r requirements.txt
2. python manage.py migrate
3. python manage.py runserver
4. Open http://127.0.0.1:8000/
